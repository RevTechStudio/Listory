# Listory - 再利用可能な階層型チェックリスト管理アプリ

## 🧭 コンセプト概要

単発的なTODOリストや一時的なチェックシートとは異なり、あらかじめ作成したチェックリストを**テンプレートとして登録し、繰り返し利用できる**ことを目的としています。  
業務用途から日常生活まで、幅広いシーンでご活用いただけます。

## 🎯 基本アイデア

| 要素 | 内容 |
|------|------|
| **チェック項目** | チェック対象となる単位です。再利用可能な要素として登録します（例：持ち物、確認事項、作業内容など）。 |
| **チェックリストテンプレート** | 項目を組み合わせて構成するテンプレートです。階層構造で整理され、複製して何度でも利用できます。 |
| **チェックリスト生成** | テンプレートをもとに、新しいチェックリストを作成します。各項目の完了／未完了を管理します。 |
| **テンプレート再利用** | 一度作成したテンプレートを別の場面で使い回すことができます。修正や拡張も容易に行えます。 |

## 🧠 Listoryの特徴

| 観点 | 内容 |
|------|------|
| **階層構造管理** | 親子関係を持った項目で複雑なチェックリストも整理できます。大項目→中項目→小項目のツリー構造を採用しています。 |
| **再利用性の高さ** | テンプレートとして登録したチェックリストを、旅行・点検・買い物などさまざまな用途に繰り返し利用できます。 |
| **構造的な整理** | 項目をグループ化して整理することができます。カテゴリごとのチェックリストをまとめて管理します。 |
| **柔軟な適用範囲** | 日常生活・業務・教育など、用途を問わず自由にカスタマイズできます。 |
| **シンプルな操作性** | 各項目の完了／未完了を直感的にチェックできます。必要に応じてメモや添付ファイルも追加できます。 |

## 📊 ステータス管理

### チェックリストテンプレートステータス

| ステータス | 説明 |
|-----------|------|
| **Active（アクティブ）** | 通常使用中のテンプレートです。新規チェックリストの生成が可能です。 |
| **Editing（編集中）** | 編集中のテンプレートです。一時的に新規生成を制限します。 |
| **Archive（アーカイブ）** | 保管中のテンプレートです。参照は可能ですが新規生成はできません。 |
| **Deleted（論理削除）** | 削除済みテンプレートです。復元可能な状態で保持します。 |

### チェックリストステータス

| ステータス | 説明 |
|-----------|------|
| **Active（アクティブ）** | 進行中のチェックリストです。編集・チェック操作が可能です。 |
| **Archive（アーカイブ）** | 完了済みチェックリストです。参照のみ可能です。 |
| **Deleted（論理削除）** | 削除済みチェックリストです。復元可能な状態で保持します。 |

## 🌳 階層構造の特徴

### ツリーベースの項目管理

- 親項目と子項目によるネスト構造を採用しています
- ドラッグ＆ドロップでの階層変更が可能です
- 折りたたみ表示で見やすいインターフェースを提供します
- 進捗状況の継承（子項目の進捗を親項目に反映）を行います

### 柔軟な構造設計

- 無制限の深いネストをサポートします
- 項目の移動・コピー・貼り付けが可能です
- テンプレート間での項目の再利用ができます
- 部分的なテンプレートのインポート/エクスポートをサポートします

## 🔄 テンプレートとチェックリストの関係性

### 独立した管理

- チェックリスト生成時点で、元のテンプレートから独立します
- 生成されたチェックリストは独自に管理されます
- 元テンプレートの情報（ID・バージョンなど）は保持します

### 変更の影響範囲

- **テンプレートの編集** → 既存のチェックリストには自動反映されません
- 各チェックリストは生成時の状態を維持します

### オプション機能

- 明示的な更新機能を提供します
- ユーザーが任意でテンプレートの変更を反映できます
- 更新のタイミングをユーザーが制御できます

## 🧩 まとめ

**Listory**は、**「チェックリストをテンプレート化し、階層構造で管理する」**ことを中核とした、**再利用可能なチェックリスト管理プラットフォーム**です。

階層構造による直感的な項目整理と、テンプレートベースの効率的な再利用により、単なるTODO管理を超えた**業務プロセス支援ツール**としての価値を提供します。

詳細なステータス管理により、テンプレートとチェックリストのライフサイクルを明確に区別し、組織的な運用を可能にします。チェック内容を都度作り直す手間をなくし、一度設計したリストをあらゆる場面で効率的に使い回すことで、個人の生産性向上から組織の業務標準化までをサポートします。
